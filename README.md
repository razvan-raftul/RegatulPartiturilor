# Regatul Partiturilor

Program pentru Windows care citește partituri pentru muzicieni nevăzători, accesibil cu NVDA:
în cuvinte, măsură cu măsură și mână cu mână („Măsura 3. Mâna dreaptă: mi 5 optime, sol 5 optime...”),
și în Braille muzical (pe ecran sau ca fișier BRF pentru imprimantă).

Descărcare: [RegatulPartiturilor-Setup.exe](https://github.com/razvan-raftul/RegatulPartiturilor/releases/download/latest/RegatulPartiturilor-Setup.exe).
Programul se actualizează singur la pornire.

Formate: MusicXML, MXL, MIDI, ABC; MuseScore (cu MuseScore instalat); PDF și poze (cu Audiveris instalat).
Făcut cu Python, wxPython și music21.
